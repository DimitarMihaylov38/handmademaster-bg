# HandmadeMaster BG

HandmadeMaster BG е React SPA приложение за представяне на български майстори и техните ръчно изработени продукти.

Приложението позволява на посетители да разглеждат каталог с продукти и профили на майстори, а регистрираните потребители могат да създават и управляват собствен профил, да добавят продукти и да запазват любими изделия.

## Основни функционалности

### Публична част

Всеки посетител може да:

- разглежда началната страница;
- разглежда всички продукти;
- отваря детайлна страница на продукт;
- разглежда всички майстори;
- отваря профил на конкретен майстор;
- използва търсене и филтриране на продуктите;
- филтрира по категория;
- филтрира по статус;
- филтрира по минимална и максимална цена;
- регистрира нов потребителски профил;
- влиза в съществуващ профил.

### Регистрирани потребители

Регистрираният потребител може да:

- редактира своя профил;
- добавя профилна снимка;
- добавя нов продукт;
- качва снимка на продукт;
- редактира собствен продукт;
- сменя снимката на собствен продукт;
- изтрива собствен продукт;
- добавя чужди продукти в любими;
- премахва продукти от любими;
- разглежда собствен списък с любими продукти;
- излиза от профила си.

## Права на потребителите

### Guest

Потребител без активна сесия има достъп до:

- `/`
- `/products`
- `/products/:productId`
- `/masters`
- `/masters/:masterId`
- `/login`
- `/register`

Няма достъп до частните страници.

### Authenticated User

Логнат потребител има достъп до:

- `/profile`
- `/profile/edit`
- `/favorites`
- `/products/create`
- `/products/:productId/edit`

Редакция и изтриване на продукт са достъпни само за неговия собственик.

---

## Routing

Основните маршрути в приложението са:

- `/` — Начална страница
- `/products` — Каталог с всички продукти
- `/products/:productId` — Детайлна страница за продукт
- `/products/create` — Добавяне на нов продукт
- `/products/:productId/edit` — Редактиране на собствен продукт
- `/masters` — Списък с всички майстори
- `/masters/:masterId` — Профил на конкретен майстор
- `/login` — Вход
- `/register` — Регистрация
- `/profile` — Потребителски профил
- `/profile/edit` — Редактиране на профил
- `/favorites` — Любими продукти
- `*` — 404 страница

## Authentication и Route Guards

Приложението използва Supabase Authentication.

Authentication състоянието се управлява чрез React Context API.

Използвани са два route guard компонента:

### AuthGuard

Позволява достъп само на логнати потребители.

При опит за достъп без активна сесия потребителят се пренасочва към `/login`.

### GuestGuard

Позволява достъп до `/login` и `/register` само на гости.

Ако логнат потребител отвори тези маршрути, той се пренасочва към началната страница.

- `website`

- `created_at`

Основни полета:

- `id`

- `price`

- `status`
- `main_image_url`

### favorites

## Row Level Security

Supabase Row Level Security е активиран.

Основните правила са:

- публично четене на продукти;
- публично четене на профили;
- потребител може да редактира само собствения си профил;
- потребител може да добавя продукт само от свое име;
- потребител може да редактира само собствен продукт;
- потребител може да изтрива само собствен продукт;
- потребител може да вижда само собствените си favorites;
- потребител може да добавя favorite само за себе си;
- потребител може да изтрива само собствен favorite.

## Supabase Storage

Използвани са два Storage bucket-а:

### product-images

Използва се за снимки на продуктите.

### profile-images

## Image Upload

При добавяне на продукт потребителят може да избере изображение директно от компютъра си.

Изображението се качва в Supabase Storage и публичният URL се записва към продукта.

При редактиране може да бъде качена нова снимка.

Профилната снимка също се качва директно в Supabase Storage.

Преди записване на нова профилна снимка се показва локален preview.

## Локално стартиране

Клониране на repository:

`git clone https://github.com/DimitarMihaylov38/handmademaster-bg.git`

Влизане в проекта:

`cd handmademaster-bg`

Инсталиране на dependencies:

`npm install`

Създаване на `.env` файл със следните променливи:

`VITE_SUPABASE_URL=YOUR_SUPABASE_URL`

Стартиране:

`npm run dev`

`http://localhost:5173/`

## Functional Guide

### Регистрация

1. Отвори `Регистрация`.
2. Въведи име, email и парола.
3. Повтори паролата.
4. Натисни `Регистрация`.

След успешна регистрация се създават:

- Supabase Auth user;
- profile запис в базата.

### Вход

1. Отвори `Вход`.
2. Въведи email.
3. Въведи парола.
4. Натисни `Вход`.

### Редактиране на профил

1. Влез в приложението.
2. Отвори `Моят профил`.
3. Натисни `Редактирай профила`.
4. Попълни информацията.
5. По желание избери профилна снимка.
6. Натисни `Запази промените`.

### Добавяне на продукт

1. Влез в приложението.
2. Натисни `Добави продукт`.
3. Попълни име.
4. Попълни описание.
5. Задай цена.
6. Избери категория.
7. Избери статус.
8. Избери снимка.
9. Натисни `Добави продукта`.

### Редактиране на продукт

1. Отвори свой продукт.
2. Натисни `Редактирай`.
3. Промени желаните данни.
4. По желание избери нова снимка.
5. Натисни `Запази промените`.

### Изтриване на продукт

1. Отвори свой продукт.
2. Натисни `Изтрий`.
3. Потвърди изтриването.

### Любими

1. Влез в профила си.
2. Отвори чужд продукт.
3. Натисни `Добави в любими`.
4. Отвори `Любими`.
5. За премахване натисни `Премахни от любими`.

### Търсене и филтри

В `/products` могат да се комбинират:

- текстово търсене;
- категория;
- статус;
- цена от;
- цена до.

## Project Purpose

Целта на HandmadeMaster BG е да предостави лесен начин български майстори да представят своите ръчно изработени изделия, а посетителите да могат да откриват продукти и техните създатели на едно място.

Приложението е информационен каталог и не съдържа система за директни плащания или checkout.
